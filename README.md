# CIS216_WK10_VIBECODING

## Student Record Manager

Run the program with:

```bash
python VIBE.py
```

The menu supports adding students, recording test scores, viewing individual
records, listing all students, and removing records. Scores must be between 0
and 100. Letter grades are calculated from the average:

- A: 90-100
- B: 80-89
- C: 70-79
- D: 60-69
- F: below 60
